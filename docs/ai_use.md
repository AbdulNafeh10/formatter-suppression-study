# AI assistance

AI tools assisted with implementation, debugging, controlled input generation,
analysis scripts, literature checks and writing. The numerical results came from
actual formatter and linter runs. Source, AST, token, diagnostic and reproduction
checks were performed with deterministic tools.

The controlled examples were AI-assisted templates with systematic directive
variants. They were not handwritten natural-source observations. Repository inputs
were archived without study-generated edits; their authors' AI use is unknown.

The supplementary ambiguity review used a separate AI-assisted procedure. It was
not independent human adjudication. The same development process supplied code,
examples, tests and interpretation, so passing checks do not establish independent
detector accuracy. No precision, recall or F1 is claimed.

The public text uses first-person singular for the independent project, not to
assert sole human authorship. The author should review the draft, explain the
methods in their own words and check any submission's attribution requirements.
The earlier detailed disclosure is retained in
the preserved original repository (the historical note is omitted from this public export).
