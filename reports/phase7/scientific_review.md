# Scientific consistency review

Reviewed 2026-11-03 UTC by the same AI-assisted research process. This is an
internal consistency review, not independent scientific assessment.

| Check | Finding and evidence |
|---|---|
| Main units | 200 controlled and 40 natural original inputs; 400 and 80 primary source-formatter comparisons. Repeats and native sensitivity stay separate. See frozen source manifests and primary JSONL exports. |
| Drift definition | Visibility changes require corresponding underlying diagnostics and the strict AST gate. A changed line number, equal count or text diff is insufficient. See Phase 2 protocol and matching/classifier implementation. |
| Controlled denominator | Each formatter has 200 scheduled and 184 resolved comparisons; 16 remain ambiguous. Scheduled and resolved rates are labeled separately. See Phase 5 metrics and report claim audit. |
| Pairing | The complete-pair comparison uses the same 184 original inputs. Template treatments are related; independent per-variant binomial inference is not used. |
| Diagnostic direction | Newly hidden/exposed are visibility transitions, not confirmation that a warning is correct or that a formatter violates its intended policy. Binary drift overlap does not establish direction agreement. |
| Natural negative result | No confirmed drift is reported. Four strict AST exclusions remain exclusions; normalization of TypeIgnore line fields is secondary. No positive resampling or silent label replacement occurred. |
| Native status | 66 applicable native comparisons are executed measurements; 14 Requests records describe missing configuration. Full native output and selected-rule classification are separate. |
| Statistical scope | Post-count interval choices are exploratory. Conditional family/category bootstrap and family-incidence Wilson outputs do not establish population coverage. Fixed-corpus completion bounds are not confidence intervals. |
| External scope | Pinned versions, selected rules, one observed Windows environment, authored stress cases and convenience historical repositories do not support ecosystem prevalence or general formatter superiority. |
| Accuracy | Controls, interventions, unit tests and repeatability are not held-out independent labels. No precision, recall, F1 or useful deployment error rate is asserted. |
| Literature | Relevant passages and metadata are verified in Phase 6; known formatter/directive interaction is acknowledged. Targeted coverage cannot establish priority. No paper replication or inaccessible publisher-text review is claimed. |
| AI provenance | Controlled authorship and engineering/report assistance are disclosed. Natural provenance means no study-generated original source, not absence of upstream AI use. |
| Applications and release | The resume entry describes a pilot and asks the user to verify their role. No publication, external scientific endorsement, public release or sole human authorship is asserted. |
| Final reproduction | Fresh-run verification records in this directory test agreement with original evidence. They extend repeatability coverage without enlarging the independent sample or correcting model bias. |
